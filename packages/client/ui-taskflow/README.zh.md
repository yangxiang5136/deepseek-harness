# @deepseek-ai/dsh-client-ui-taskflow

[English](README.md) | 中文

TaskFlow 通过带版本的浏览器偏好 `dsh.taskflow.view.v1` 记住展开或收起状态及所选项目。刷新、重新挂载，或在同源新页面打开时会恢复该视图；明确关闭或清空项目后保持关闭，收起整条时保留项目供下次展开。偏好只在本页操作后改变，其他页面不会带动当前视图切换。待审详情卡与收口操作不会恢复。存储缺失、损坏、版本不支持或被禁用时，安全回到原来的收起且未选项目状态；保存失败时本页仍可在内存中正常使用。

TaskFlow 底部状态条是 frame 级 `shell.overlay` 槽位的第一个正式住户：收起态为 30px 迷你条，展开为规格 §6 v3.0 定义的注意力表面，包含低饱和时间史条、运行芯片行、「待你收口」托盘，以及收纳无心跳泳道和溢出项的标题浮层。时间史为空时，会区分已记录的当前任务与当天尚无已结束时段；当前任务在切换或结束后进入历史。事实经 `taskflow` Remote 命名空间（`@deepseek-ai/dsh-host-taskflow`）来自总线账本，每 10 秒重新折算。时间史、当前任务、后台任务与泳道仍按当天折算；`needs-you` 欠账按全账本折算，可跨日、跨月保留。v2 欠账只允许精确的 schema-v2 resolver 关闭：`dsh` 审计 `done` seal，或 note 以 `Superseded` 开头的 `drop` 撤回。旧 v1 欠账的 60 秒启发只读取旧 terminal 行，未来普通 v2 terminal 不能关闭它。收口勾在可用时发送目标 `event_id`，并以 `dsh-ui:seal-click` 记录确认出处。状态条把实时高度以 `--dsh-shell-bottom-clearance` 发布到 shell frame，使 ui-layout 内容止于条上沿。字号统一为五档（主角 15 / 名称 13 / 元信息 12 / 按钮与标签 12 / 提示 11px，`--tf-font-*` 定义在状态条上，`typeScale.ts` 同步），字号跟着重要程度走：当前任务与「待你收口」在各自区域里最醒目。展开时，标题旁的琥珀色「无心跳 N」角标统计静默的泳道与后台任务，点开即是清单；静默过的泳道在派活方完成时照样关闭，已结束的工作不会一直挂在那里。

标题栏的「项目」选择器和「待你收口」里的项目名都能打开项目树（TaskFlow 里的 Branch Compass）：主线上每条未了结的分支从它开始的位置岔出（进行中、无动静、等你处理或停放）；主线在「现在」之后接上这个项目在总线 todo 里的待办。选择器纳入有已保存审阅计划、近 7 天有活动、有未收口或停放欠账、有已保存主线，或有总线未完成待办的项目。待办文件在启动和切换项目时读取；读取失败会显示在标题栏或已打开的树里。已了结的分支不画，保留在一行汇总中。树里不显示分支百分比或重心评价。主线由人按项目指定（鼠标移到任务行上浮现「设为主线」小按钮；存在浏览器 `localStorage`），未指定时默认近 7 天最活跃的任务。点托盘里的一行，或项目树上等你处理 / 停放的状态牌，打开的是同一张详情卡：现状、收口入口、说明、提出后的最新动态、最近几条账本记录；一段可复制的续接 prompt（前因后果、Sean 在这个项目上最近的收口反馈、`att` 记账命令，任意 AI 都能接着做并让 TaskFlow 同步状态）；以及可附一行留言的收口——留言就是给 AI 的反馈，以后接手这个项目的 AI 开工前会读到。标题浮层只剩无心跳泳道和溢出芯片，待收口只在托盘里。`park` 欠账（停放的支线）不进收口托盘和运行行，只出现在项目树上。

有已保存计划的项目在标题之后、分支树之前显示“建议审阅顺序”；无计划项目保持原树，不插入空审阅区。顺序通过 `taskflow.reviewPlans()` 每 10 秒独立读取，不依赖切换项目。严格的第一版计划格式保存条目顺序、建议前项、明确覆盖顺序及来源消息观察。简洁列表逐字显示 `chatTitle` 中的原生聊天名称，同一 `threadId` 的多个阅读步骤合为一行，可并行聊天另列。有人工排序覆盖的聊天取其最早覆盖顺序，其他聊天取最早步骤顺序。聊天名称缺失时显示带聊天 ID 的明确待同步提示；没有聊天 ID 的通用计划条目仍使用条目标题。每个聊天最多一条合并状态，仅由精确账本记录推导；合并行不会关闭或移除任何欠账。来源标为 pending 表示已观察到但尚未核对的新消息，计划保存时间不代表同步完成。待核对来源保留第一条尚未核对消息的定位；已核对来源记录匹配的核对消息并清除待核对起点。来源定位与监听健康折叠在详情中。健康区分未接入、检查出错及距最近扫描超过 30 秒的可能中断，未接入的表面单独列出。读取或验证失败时保留上次有效计划并显示错误。审阅操作保留在原托盘，托盘入口打开精确欠账，同一任务名的多项审阅分别处理；未列入计划的欠账仍保留在托盘里。顺序列表不增加复制或查看记录按钮。

## 模型体验

无。状态条是基于总线账本的人面表面；这里没有任何内容进入模型请求。

#### KV Cache 影响

无；该包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **几何尺寸靠手工对齐 CSS**——文字按所属字号角色测量（canvas `measureText`，回退 `estTextW`），行宽与时间条宽为实测；但 `ProjectPanel.tsx` 的 SVG 树常量与 `fold.ts` 的 `CHIP` 芯片盒模型是手抄的 CSS 数值，只有字号变量（`TF_TYPE`）和芯片最大宽度有测试锁定。
- **队列动作不在范围内**（规格 §6 v3.0 动作表）。
