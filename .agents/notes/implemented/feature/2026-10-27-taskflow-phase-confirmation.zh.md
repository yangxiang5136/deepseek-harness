# Agent Note: 可追溯反思的人类阶段确认

Status: implemented

[English](2026-10-27-taskflow-phase-confirmation.md) | 中文

## Problem

本人可能在对话中结束一个工作阶段，也可能点击 TaskFlow 按钮。只接受按钮确认会让已经完成的工作继续等待，接受任意来源引用又会让 AI 编造人的批准。阶段结束还需要保留材料，供以后反思。

## Decision

TaskFlow host 在原生本地 Codex 记录的精确字节偏移处核验逐字真人消息，再复用与按钮相同的精确债务收口事务。host 检查原文位置、原生会话、真人内容标记和逐字引文。调用者负责将本人原意映射到选中的具体债务；关键词匹配不能关闭一个项目的全部工作。其他记录来源需要各自可核验的适配器。

详情动作直接表达本人意图：本阶段结束，交史官复盘。审计收口保留确认来源。外部史官消费者从有效精确收口派生持久且可去重的任务，另行记录实际阅读和反思。收口不证明史官已读，也不证明整个项目已获接受。原始材料与续接入口继续保留。

## Alternatives considered

- 把普通完成记录当成批准：执行与本人决定的来源不同，因此不采用。
- 允许调用者随意提供确认引用：引用需要 host 核验，因此不采用。
- 用宽泛完成关键词自动结束阶段：一句话可能只涉及仍有相关未决事项的局部阶段，因此不采用。
- 在收口时承诺反思已完成：阅读可能失败，也可能在阶段结束后仍排队，因此不采用。

## Consequences

对话确认需要支持的原生记录和调用者选定的准确范围。host 拒绝不支持或被注入的来源、不完整记录、缺失的逐字引文和链接路径。反思可用性由独立消费者负责，其回执必须说明实际覆盖和未决材料。界面的撤销窗口保持不变，两种入口使用同一精确收口事务。
