# Agent Note: 独立的方舟配色

Status: implemented

[English](2026-10-28-ark-color-palette.md) | 中文

## 问题

DSH 与 TaskFlow 需要共享方舟视觉方向，同时保留布局、任务语义和现有行为。可撤回的配色选择还需要在刷新后保留用户的浅色、深色或跟随系统偏好，并避免插件加载期间显示另一套配色。

## 决策

主题所有者将 `ui-theme.palette` 持久化为 `default` 或 `ark`，与 `ui-theme.preference` 独立。已有设置解析为 `default`。“外观”设置在原有明暗选择旁提供“原版”和“方舟”；选择配色会立即改变颜色，并沿用现有 Host settings 生命周期。远程浏览器按相同权限规则保留进程内选择。

方舟配色是一层共享语义 token，同时提供浅色和深色值。它叠在已注册主题 token 之上，显式 `overrideTokens()` 来源层之下。切回原版会移除该层。TaskFlow 消费主题所有者提供的历史和阴影别名，同时保留项目身份配色、浅色数据配色上的深色标签，以及运行、等待、错误的不同含义。几何尺寸、导航、任务数据和阶段确认不在此次配色改动范围内。

浅色配色参考本地方舟 UI 组件库候选 `MSC_AI/outputs/ark-ui-library-v1/src/vendor/collaboration/styles/ark-voice-tokens.scss`；该候选是来源参考，不是已部署方舟配色的证据。深色配色将同一视觉方向适配到深色背景。两套配色都不构成通用方舟设计规范或人工审美验收。

[插件激活前的引导](../bug-fix/2026-08-10-pre-plugin-theme-bootstrap.md)在外壳渲染前嵌入所选配色与明暗模式，记录其内联 token 名称，并让呈现器接管运行时快照时移除这些变量。[Host settings 偏好生命周期](../bug-fix/2026-08-06-host-backed-web-preferences.md)仍拥有持久化设置；配色不引入浏览器存储权威来源。

## 考虑过的替代方案

**替换基础配色。** 这会让原版颜色无法作为直接对照和回退选择。独立覆盖层保留两套配色。

**将方舟浅色、深色注册为主题 id。** 这会把视觉身份与明暗选择绑定，并使跟随操作系统更复杂。独立的配色和明暗选择保留该行为。

**把 TaskFlow 所有项目都改成紫色。** 项目颜色编码的是身份，而非界面装饰。保留其差异可以延续信息，同时让共享控件与聚合历史采用方舟配色。

## 后果

颜色变化可以撤回，不改变布局或任务状态。内置配色与明暗设置共享一个带 revision 的 namespace，并沿用既有写入失败恢复机制。显式覆盖层可以有意与所选配色不同，其下的第三方主题 token 则可能被方舟 token 覆盖。
