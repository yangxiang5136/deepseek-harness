# Agent Note：TaskFlow 项目入口独立于收口欠账

Status: implemented

[English](2026-10-07-taskflow-project-access.md) | 中文

## Problem

只有 start 的任务占据当前任务行，而不是已结束时间线。即使当前任务可见，空时间线仍声称没有注意力事件。项目树只能通过「待你收口」里的项目名打开，没有收口欠账的项目缺少入口。

## Decision

空时间线说明当前任务已记录，或当天尚无已结束时段。展开态标题栏的原生「项目」选择器独立于托盘打开现有项目树。选项合并项目树近 7 天的活动、任何时间的未收口和停放欠账、已保存的主线，以及已映射总线文件里的未完成待办；项目别名合并为一个选项。待办文件在启动和切换项目时读取；失败显示在标题栏或项目树，过期响应被丢弃。

## Alternatives considered

依赖托盘仍会让无欠账项目缺少入口。把尚未结束的任务加入历史，会为了修正空状态文案而改变当前工作与已结束时段的区别。

## Consequences

只有当前任务或只有待办的项目都有直接入口。账本折算、30 分钟静默规则，以及经人确认的精确收口语义保持不变。页面持续打开时新增的纯待办项目，在刷新或切换项目后出现；待办发现不会增加另一条轮询循环。
